# 営業日スケジューラ

タスクと日数を入れるだけで、土日・祝日・休業日を除いた営業日ベースの納品スケジュールを作るツールです。
ガントチャートで日程を確認・調整し、そのままチャットやメールに貼れるテキスト、スプレッドシートに貼れる表としてコピーできます。

HTML ファイル1つで動き、インストールやビルドは不要です。

**公開URL：https://biz-day-scheduler.vercel.app/**

## 使い方

1. [公開URL](https://biz-day-scheduler.vercel.app/) を開きます（ローカルなら `index.html` をブラウザで開くだけでも使えます）。
2. 「開始日から計算」か「納期から逆算」を選び、基準日を入れます。
3. タスク表の黄色い欄（タスク名・日数・開始タイミング）を入力します。
4. ガントチャートで日程を確認し、必要ならバーをドラッグして調整します。
5. 「テキストをコピー」または「表としてコピー」で結果を共有します。

入力内容はブラウザ（`localStorage`）に自動保存されます。

## 主な機能

### 2つの計算モード
- **開始日から計算**：上のタスクから順に、開始日から前詰めで日付を割り振ります。
- **納期から逆算**：下のタスクから順に、納期に間に合うように後ろ詰めで割り振ります。納期を過ぎるタスクには警告が出ます。

### 開始タイミング
| 設定 | 動き |
|---|---|
| 上に続く | 上のタスクが終わった翌営業日に始まる |
| 上と同時 | 上のタスクと同じ日に始まる（並行作業）。並行したタスクがすべて終わってから次へ進む |
| 初日から／別の流れで | 全体の初日（逆算時は納期）を基準に、別系統として並べる |
| 開始日を固定／終了日を固定 | 指定した日に始める（逆算時は、指定した日までに終える） |

日数を空欄にした行は見出しになります。

### ガントチャート
- バーを左右にドラッグすると日付が動きます（そのタスクは日付固定になります）。
- バーの両端をドラッグすると日数が変わります。
- タスク名を上下にドラッグすると順番を入れ替えられます。
- キーボード操作：バーを選んで `←` `→` で移動、`Shift` + `←` `→` で日数を変更します。
- 直前の操作は「元に戻す」で取り消せます。

### 出力
- **テキスト**：`10/5-10/6: 要件整理` の形式です。
- **表（TSV）**：タスク名・日数・開始日・終了日の4列で、Google スプレッドシートや Excel にそのまま貼り付けられます。

### 休業日
- 2026〜2027年の国民の祝日（内閣府発表）を最初から登録しています。
- 年末年始・夏季休暇などは「休業日を追加」に1行1日で書き足せます（例：`2026/12/29`）。

## 注意事項
- 祝日データは **2027年末まで** です。2028年以降にかかるスケジュールでは、祝日を「休業日を追加」に手で入れてください。
- 保存先はブラウザごとの `localStorage` です。別のブラウザや端末とは共有されません。

## 開発メモ
- 構成は `index.html` だけです（HTML / CSS / JavaScript をすべて含み、外部ライブラリは使っていません。フォントは Google Fonts から読み込みます）。
- 計算部分（`compute` / `buildText` / `buildTsv` など）は Node.js から `require` で読み込めるため、単体テストに使えます。

```js
// 例：<script> の中身を取り出して lib.js に保存した場合
const lib = require('./lib.js');
```
