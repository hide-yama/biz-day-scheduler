# 営業日スケジューラ

タスクと日数を入れるだけで、土日・祝日・休業日を除いた営業日ベースの納品スケジュールを作るツールです。
ガントチャートで日程を確認・調整し、そのままチャットやメールに貼れるテキスト、スプレッドシートに貼れる表としてコピーできます。

HTML ファイル1つで動き、インストールやビルドは不要です。

**公開URL：https://biz-day-scheduler.vercel.app/**

## 使い方

1. [公開URL](https://biz-day-scheduler.vercel.app/) を開きます（ローカルなら `index.html` をブラウザで開くだけでも使えます）。
2. 「開始日から計算」か「納期から逆算」を選び、基準日を入れます。
3. タスク表の黄色い欄（タスク名・日数・開始タイミング）を入力します。
4. ガントチャートで日程を確認し、必要ならバーをドラッグして調整します。
5. 「テキストをコピー」または「表としてコピー」で結果を共有します。

入力内容はブラウザ（`localStorage`）に自動保存されます。

## 主な機能

### 2つの計算モード
- **開始日から計算**：上のタスクから順に、開始日から前詰めで日付を割り振ります。
- **納期から逆算**：下のタスクから順に、納期に間に合うように後ろ詰めで割り振ります。納期を過ぎるタスクには警告が出ます。

### 開始タイミング
| 設定 | 動き |
|---|---|
| 上に続く | 上のタスクが終わった翌営業日に始まる |
| 上と同時 | 上のタスクと同じ日に始まる（並行作業）。並行したタスクがすべて終わってから次へ進む |
| 初日から／別の流れで | 全体の初日（逆算時は納期）を基準に、別系統として並べる |
| 開始日を固定／終了日を固定 | 指定した日に始める（逆算時は、指定した日までに終える） |

日数を空欄にした行は見出しになります。

### ガントチャート
- バーを左右にドラッグすると日付が動きます（そのタスクは日付固定になります）。
- バーの両端をドラッグすると日数が変わります。
- タスク名を上下にドラッグすると順番を入れ替えられます。
- キーボード操作：バーを選んで `←` `→` で移動、`Shift` + `←` `→` で日数を変更します。
- 直前の操作は「元に戻す」で取り消せます。

### 出力
- 共有用テキストは直接書き換えられます。`10/5-10/6: 要件整理` のように日付を書いた行はその期間のタスク（日数は営業日で数え直し）、`デザイン制作 3日` のように日数だけの行は上に続くタスクになります。日付を書き換えていない行は元の開始タイミングのまま、書き換えた行は日付固定になります。
- タスク名・日数の欄で Enter を押すと、すぐ下に新しい行が増えます。
- **テキスト**：`10/5-10/6: 要件整理` の形式です。
- **表（TSV）**：タスク名・日数・開始日・終了日の4列で、Google スプレッドシートや Excel にそのまま貼り付けられます。

### 休業日
- 2026〜2027年の国民の祝日（内閣府発表）を最初から登録しています。
- 年末年始・夏季休暇などは「休業日を追加」に1行1日で書き足せます（例：`2026/12/29`）。

## タスクスケジューラ（`task.html`）

1人で1日の仕事のタスクを組むためのページです。
公開URL：https://biz-day-scheduler.vercel.app/task.html

- タスクと所要時間を入れると、開始時刻から順に時刻を割り振ります。会議など時刻が決まっているものは、その行の開始時刻を書き換えると固定されます（× で解除）。
- 終わったタスクは左のチェックで完了にできます。上部に「完了 ○/○・残り○時間」が出て、ガントのバーも薄くなります。
- 日付は「← 今日 →」で切り替えられ、日ごとに自動保存されます（何も入れていない日は保存しません）。
- ガントチャートはタイムスケジューラと同じくドラッグで編集できます。
- 共有用テキストでは完了したタスクに ✓ がつき、表としてコピーすると「完了」列がつきます。
- タスク名・所要時間の欄で Enter を押すと、すぐ下に新しい行が増えてそこへ移ります（日本語入力の変換確定の Enter では増えません）。3ページ共通です。
- **共有用テキストは直接編集できます。** 書き換えると表とガントチャートに反映されます（3ページ共通。書き方は各ページの説明を参照）。
  - `9:00-9:30 メール確認` のように時刻を書いた行はその時刻のタスクになります。時刻を書き換えていない行は元のまま（固定／前に続く）で、書き換えた行や新しい行は前のタスクとつながらなければ開始時刻を固定します。
  - `資料作成 1時間` のように所要時間だけ書いた行は前のタスクに続きます。行末（または行頭）の ✓ は完了、それ以外の行は見出しになります。
  - 読み取れない行（書きかけの時刻など）は反映せず、テキスト欄の下に知らせます。直すまでその行は消しません。

## タイムスケジューラ（`day.html`）

旅行や出張など、何日かにわたる予定や複数人の別行動を時刻で組み立てるページです。
公開URL：https://biz-day-scheduler.vercel.app/day.html

- 予定と所要時間（`30` / `1:30` / `1時間半` など）を入れると、その日の開始時刻から上の予定に続けて時刻を割り振ります。
- 電車の発車時刻など決まった時刻がある予定は、その行の開始時刻を書き換えると固定されます（× で解除）。前の予定と重なると警告が出て、すき間は「前と○分空き」と表示されます。
- **メンバー（別行動）**：複数人で動くときはメンバーを登録すると、予定ごとに「だれ」（全員／各メンバー）を選べます。各自の予定はその人の前の予定に続き、全員の予定は全員がそろってから始まります。予定はメンバーごとに色分けされます。
- **共有用テキストの編集**：`■ 10/10（土） 1日目` の行が日の区切りで、日を足したりタイトルを変えたりもできます。`[Aさん]` をつけるとその人の予定になります（メンバーにいない名前は全員の予定として扱い、知らせます）。
- **ガントチャート**：常に表示します（予定1つにつき1行）。バーをドラッグすると開始時刻（その時刻に固定）、右端で所要時間、左端で開始時刻（終わりは固定）が5分刻みで変わります。予定名の上下ドラッグで並べ替え、「元に戻す」、キーボード操作（← → / Shift＋← →）にも対応しています。
- 日付タブで日を追加でき、予定は「日を移す」で別の日へ移せます。24時を過ぎる予定は「翌1:00」のように表示します。
- プランは複数保存でき、切り替え・複製・削除ができます（保存先は `localStorage`）。
- 出力は全日程／その日だけのテキストと、表（日付・開始・終了・予定・所要時間。メンバーがいるときは「だれ」も）です。
- **共有リンク**：プランの中身を圧縮して URL（`#p=...`）に入れます。サーバーやデータベースは使いません。開いた人のブラウザにプランのコピーが追加されるだけなので、あとからの編集は相手には反映されません。

## 注意事項
- 祝日データは **2027年末まで** です。2028年以降にかかるスケジュールでは、祝日を「休業日を追加」に手で入れてください。
- 保存先はブラウザごとの `localStorage` です。別のブラウザや端末とは共有されません。

## 開発メモ
- 構成は `index.html`（営業日スケジューラ）・`task.html`（タスクスケジューラ）・`day.html`（タイムスケジューラ）の3ファイルで、どれも単体で動きます（HTML / CSS / JavaScript をすべて含み、外部ライブラリは使っていません。フォントは Google Fonts から読み込みます）。
- 計算部分（`index.html` の `compute` / `buildText` / `buildTsv`、`day.html` の `computeDay` / `buildText` / `buildTsv` / `parseDur` など）は Node.js から `require` で読み込めるため、単体テストに使えます。

```js
// 例：<script> の中身を取り出して lib.js に保存した場合
const lib = require('./lib.js');
```
